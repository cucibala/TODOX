# Assets 目录

这个目录用于存放应用资源文件。

## ⚠️ 重要提示

**打包前必须创建托盘图标，否则打包后托盘图标不显示！**

## 托盘图标

请在此目录放置 `tray-icon.png` 作为系统托盘图标。

**推荐尺寸**: 32x32 像素（PNG格式，支持透明背景）

## 快速创建托盘图标

### 方法1：在线生成（最简单）
1. 访问 https://www.favicon-generator.org/
2. 搜索 "checklist" 或 "todo" 图标
3. 下载 32x32 PNG 格式
4. 重命名为 `tray-icon.png`
5. 放到此目录

### 方法2：使用 Emoji（快速）
1. 访问 https://favicon.io/emoji-favicons/
2. 选择合适的 emoji（如 ✅ 或 📋）
3. 下载生成的图标
4. 重命名为 `tray-icon.png`

### 方法3：手动绘制
使用 Windows 画图或其他工具：
1. 创建 32x32 像素的图像
2. 绘制简单图标（建议使用应用主题色 #667eea）
3. 保存为 `tray-icon.png`

## 图标设计建议

- **颜色**：使用应用主题色（紫色 #667eea）
- **背景**：透明或白色
- **图案**：勾选框、列表图标或字母 "T"
- **风格**：简洁明了，在小尺寸下清晰可见

## 如何添加托盘图标

1. 准备好 `tray-icon.png` 文件（32x32像素）
2. 放置在此目录中
3. 重新启动应用即可看到图标
4. 打包前确保图标文件存在

## 验证图标

运行应用后，查看系统托盘（任务栏右下角）：
- Windows: 任务栏右下角
- macOS: 菜单栏右上角
- Linux: 系统托盘区域

如果没有看到图标，检查：
1. 文件名是否为 `tray-icon.png`（小写）
2. 文件是否在 `assets/` 目录
3. 图片格式是否为 PNG
4. 图片尺寸是否合适（推荐32x32）
