# TodoX project overview

## Purpose
TodoX is a modern desktop task/todo application with project management, documents (Markdown), built-in AI assistant features, and local persistence.

## Tech stack
- Desktop: Electron (`main.js`, `preload.js`)
- Renderer: Vue 3 + Pinia + Vite (under `src/`)
- Storage: SQLite via `better-sqlite3` (`database.js`)

## High-level architecture
- Electron main process owns filesystem access, window lifecycle, tray/menu, and the SQLite database.
- Renderer communicates with main via IPC exposed through `window.electronAPI` in `preload.js`.
- Vite dev server runs on `http://localhost:5173` and Electron loads it in dev; in prod Electron loads `dist-vue/`.

## Repo layout
- `main.js`: Electron main process + IPC handlers
- `preload.js`: IPC bridge via `contextBridge`
- `database.js`: schema + migrations/versioning
- `assets/`: app icon/assets
- `src/`: Vue/Vite project
  - `src/src/`: renderer code (`components/`, `pages/`, `stores/`, `utils/`, `assets/`)
- `dist-vue/`: built renderer output (generated)
- `dist/`: packaged output (generated by `electron-builder`)
- `test/`: ad-hoc scripts (not a formal automated test suite)
