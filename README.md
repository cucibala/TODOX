# TodoX - 现代化任务清单应用

一个基于 Electron 开发的桌面任务清单程序，界面美观，功能完善。

## 功能特性

### 核心功能
- ✅ 添加、编辑、删除任务
- ✅ 标记任务完成/未完成
- ✅ 任务优先级设置（高/中/低）
- ✅ 📅 任务截止日期设置
- ✅ 🖼️ 任务图片附件上传
- ✅ 图片查看器（点击放大查看）
- ✅ 本地数据持久化
- ✅ 搜索和筛选功能
- ✅ 智能日期显示（今天/已过期/即将到期）

### 窗口管理
- ✅ 📌 窗口置顶（始终显示在最前面）
- ✅ 🎯 迷你模式（350px宽度，适合放在桌面角落）
- ✅ 🖥️ **桌面背景模式（新）**：显示在桌面壁纸之上，所有窗口之下
- ✅ 🎨 无边框窗口，自定义标题栏
- ✅ 💫 系统托盘支持（关闭窗口最小化到托盘）
- ✅ 🖱️ 可拖动到桌面任意位置
- ✅ 🔄 完整模式/迷你模式一键切换
- ✅ 🤖 智能定位：拖到右上角自动切换迷你模式并置顶

## 安装运行

1. 安装依赖：
```bash
npm install
```

2. 运行应用：
```bash
npm start
```

3. 开发模式（带开发者工具）：
```bash
npm run dev
```

## 使用技巧

### 窗口模式
- **完整模式**：1000x700像素，包含侧边栏、搜索、完整功能
- **迷你模式**：350x500像素，精简界面，适合桌面角落使用
- **桌面背景模式** 🆕：半透明背景，显示在桌面上，回到桌面就能看到任务清单

### 快捷操作
- 点击标题栏的 **🖥️ 桌面按钮** 进入/退出桌面背景模式
- 点击标题栏的 **📌 图钉按钮** 切换窗口置顶
- 点击标题栏的 **分屏按钮** 切换完整/迷你模式
- 点击标题栏的 **➖ 按钮** 最小化窗口
- 点击标题栏的 **✕ 按钮** 隐藏到系统托盘

### 智能定位 🤖
- **拖动窗口到屏幕右上角**（右侧30%且顶部30%区域）
- 会自动切换到迷你模式并启用置顶
- 非常适合将任务清单固定在桌面角落

### 桌面背景模式 🆕
这是一个非常实用的功能，让任务清单像桌面小部件一样使用：

**特点**：
- 🎨 半透明毛玻璃效果
- 📍 显示在所有窗口之下，但在桌面壁纸之上
- 👁️ 回到桌面即可看到任务清单
- 📝 可以直接在桌面上完成任务

**使用方法**：
1. 点击标题栏的桌面图标（显示器图标）
2. 或右键托盘图标 → 选择"桌面背景模式"
3. 窗口会变成半透明并固定在桌面上
4. 再次点击即可退出

### 系统托盘
- 右键托盘图标可以：
  - 显示窗口
  - 进入/退出桌面背景模式
  - 切换窗口置顶
  - 切换迷你/完整模式
  - 退出应用
- 双击托盘图标显示窗口

## 打包应用

### ⚠️ 打包前必做
**创建托盘图标**，否则打包后托盘不显示图标！

1. 准备一个 32x32 像素的 PNG 图标
2. 命名为 `tray-icon.png`
3. 放在 `assets/` 目录
4. 详见 `assets/README.md` 或 `创建托盘图标说明.md`

### 自动打包（根据当前系统）
```bash
npm run build
```

### 打包为 Windows 安装包
```bash
npm run build:win
```
生成文件：`dist/TodoX Setup 2.3.0.exe`

### 打包为 macOS 应用
```bash
npm run build:mac
```
生成文件：`dist/TodoX-1.0.0.dmg`

### 打包为 Linux 应用
```bash
npm run build:linux
```
生成文件：`dist/TodoX-1.0.0.AppImage` 和 `dist/todox_1.0.0_amd64.deb`

### 注意事项
- 打包后的文件在 `dist` 目录中
- Windows 安装包支持自定义安装路径和创建桌面快捷方式
- **托盘图标是必需的**：打包前必须创建 `assets/tray-icon.png`（32x32 PNG）
- 首次打包会下载必要的依赖，可能需要较长时间
