# TodoX - 现代化任务清单应用

一个基于 Electron 开发的桌面任务清单程序，界面美观，功能完善。

## 功能特性

### 核心功能
- ✅ 添加、编辑、删除任务
- ✅ 标记任务完成/未完成
- ✅ 任务优先级设置（高/中/低）
- ✅ 📅 任务截止日期设置
- ✅ 🖼️ 任务图片附件上传
- ✅ 图片查看器（点击放大查看）
- ✅ 本地数据持久化
- ✅ 搜索和筛选功能
- ✅ 智能日期显示（今天/已过期/即将到期）

### 窗口管理
- ✅ 📌 窗口置顶（始终显示在最前面）
- ✅ 🎯 迷你模式（350px宽度，适合放在桌面角落）
- ✅ 🎨 无边框窗口，自定义标题栏
- ✅ 💫 系统托盘支持（关闭窗口最小化到托盘）
- ✅ 🖱️ 可拖动到桌面任意位置
- ✅ 🔄 完整模式/迷你模式一键切换

## 安装运行

1. 安装依赖：
```bash
npm install
```

2. 运行应用：
```bash
npm start
```

3. 开发模式（带开发者工具）：
```bash
npm run dev
```

## 使用技巧

### 窗口模式
- **完整模式**：1000x700像素，包含侧边栏、搜索、完整功能
- **迷你模式**：350x500像素，精简界面，适合桌面角落使用

### 快捷操作
- 点击标题栏的 **📌 图钉按钮** 切换窗口置顶
- 点击标题栏的 **分屏按钮** 切换完整/迷你模式
- 点击标题栏的 **➖ 按钮** 最小化窗口
- 点击标题栏的 **✕ 按钮** 隐藏到系统托盘

### 系统托盘
- 右键托盘图标可以：
  - 显示窗口
  - 切换窗口置顶
  - 切换迷你/完整模式
  - 退出应用
- 双击托盘图标显示窗口

## 打包应用

### 自动打包（根据当前系统）
```bash
npm run build
```

### 打包为 Windows 安装包
```bash
npm run build:win
```
生成文件：`dist/TodoX Setup 1.0.0.exe`

### 打包为 macOS 应用
```bash
npm run build:mac
```
生成文件：`dist/TodoX-1.0.0.dmg`

### 打包为 Linux 应用
```bash
npm run build:linux
```
生成文件：`dist/TodoX-1.0.0.AppImage` 和 `dist/todox_1.0.0_amd64.deb`

### 注意事项
- 打包后的文件在 `dist` 目录中
- Windows 安装包支持自定义安装路径和创建桌面快捷方式
- 如需自定义图标，请将图标文件放在 `assets` 目录（可选）
- 首次打包会下载必要的依赖，可能需要较长时间
