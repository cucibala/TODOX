# Vue + Electron 常见问题

## 1. IPC 通信错误：An object could not be cloned

### 问题描述
在使用 Pinia Store 与 Electron 主进程通信时，可能会遇到以下错误：

```
Error: An object could not be cloned.
```

### 原因分析
Pinia 的状态是响应式对象（由 Vue 的 Proxy 包装），这些对象不能直接通过 Electron 的 `ipcRenderer.invoke` 传递给主进程。

### 解决方案

**❌ 错误写法：**
```javascript
// store.js
async function saveData() {
  await electronAPI.saveData({
    items: items.value  // 错误：直接传递响应式对象
  })
}
```

**✅ 正确写法：**
```javascript
// store.js
async function saveData() {
  await electronAPI.saveData({
    items: JSON.parse(JSON.stringify(items.value))  // 正确：转换为普通对象
  })
}
```

### 其他转换方法

1. **使用 `toRaw`**（需要深度转换）
```javascript
import { toRaw } from 'vue'

// 注意：toRaw 只转换第一层，嵌套对象需要递归处理
const plainObject = toRaw(items.value)
```

2. **使用 JSON 序列化**（推荐）
```javascript
// 最简单且彻底的方法
const plainObject = JSON.parse(JSON.stringify(items.value))
```

3. **手动构造普通对象**
```javascript
const plainObject = {
  items: items.value.map(item => ({
    id: item.id,
    name: item.name,
    // ... 其他字段
  }))
}
```

### 项目中的修复

我们在以下文件中应用了此修复：

1. **src/src/stores/project.js**
```javascript
async function saveProjects() {
  await electronAPI.saveProjects({
    projects: JSON.parse(JSON.stringify(projects.value)),
    currentProjectId: currentProjectId.value
  })
}
```

2. **src/src/stores/todo.js**
```javascript
async function saveTodos() {
  await electronAPI.saveTodos(JSON.parse(JSON.stringify(todos.value)))
}
```

## 3. 图片加载失败或显示 [object Promise]

### 问题描述
任务图片显示不出来、显示为空，或者图片 src 显示为 `[object Promise]`。

### 可能原因
1. **在模板中直接调用异步函数**（最常见）
2. 图片文件路径错误
3. 图片文件已被删除
4. 异步加载未完成

### 问题示例

**❌ 错误写法：在模板中直接调用异步函数**
```vue
<template>
  <!-- 错误：getImageSrc 返回 Promise，导致 src="[object Promise]" -->
  <img :src="getImageSrc(image)" />
</template>

<script setup>
async function getImageSrc(fileName) {
  const result = await electronAPI.readImage(fileName)
  return result.data
}
</script>
```

**✅ 正确写法：使用响应式数据**
```vue
<template>
  <!-- 正确：使用响应式缓存 -->
  <img 
    v-show="imageCache[image]" 
    :src="imageCache[image]" 
  />
</template>

<script setup>
import { ref, onMounted } from 'vue'

const imageCache = ref({})

async function loadImage(fileName) {
  if (imageCache.value[fileName]) {
    return // 已加载
  }
  
  const result = await electronAPI.readImage(fileName)
  if (result.success) {
    imageCache.value[fileName] = result.data
  }
}

onMounted(async () => {
  if (props.task.images) {
    // 并行加载所有图片
    await Promise.all(
      props.task.images.map(image => loadImage(image))
    )
  }
})
</script>
```

### 为什么会这样？

Vue 模板中的表达式是同步的，当你写 `:src="getImageSrc(image)"` 时：
1. Vue 立即调用 `getImageSrc(image)`
2. 函数返回一个 `Promise` 对象
3. Vue 将 Promise 对象转换为字符串 `[object Promise]`
4. 最终 `<img src="[object Promise]" />` 无法显示

### 正确的异步图片加载模式

```vue
<script setup>
import { ref, onMounted, watch } from 'vue'

// 1. 创建响应式缓存
const imageCache = ref({})

// 2. 定义加载函数
async function loadImage(fileName) {
  if (imageCache.value[fileName]) return
  
  const result = await electronAPI.readImage(fileName)
  if (result.success) {
    imageCache.value[fileName] = result.data
  }
}

// 3. 在生命周期中加载
onMounted(async () => {
  await loadImage(props.fileName)
})

// 4. 监听变化
watch(() => props.fileName, async (newFile) => {
  await loadImage(newFile)
})
</script>

<template>
  <!-- 5. 使用响应式数据 -->
  <img v-if="imageCache[fileName]" :src="imageCache[fileName]" />
</template>
```

## 4. 状态不同步

### 问题描述
修改了状态，但 UI 没有更新。

### 原因分析
1. 没有使用 `.value` 访问 ref
2. 直接修改了数组/对象内部，Vue 未检测到变化
3. 在异步操作中状态被覆盖

### 解决方案

**❌ 错误：**
```javascript
// 直接修改可能不会触发更新
todos.value[0].completed = true
```

**✅ 正确：**
```javascript
// 方法 1：使用 find 然后修改
const todo = todos.value.find(t => t.id === id)
if (todo) {
  todo.completed = true
}

// 方法 2：替换整个数组
todos.value = todos.value.map(t => 
  t.id === id ? { ...t, completed: true } : t
)
```

## 5. 打包后应用无法启动

### 问题描述
开发模式正常，打包后无法启动或功能异常。

### 检查清单

1. **确保 Vue 已构建**
```bash
npm run vue:build
# 检查 dist-vue/ 目录是否存在
```

2. **检查文件路径**
```javascript
// main.js
const vueDistPath = path.join(__dirname, 'dist-vue', 'index.html')
console.log('加载路径:', vueDistPath)
console.log('文件是否存在:', fs.existsSync(vueDistPath))
```

3. **检查打包配置**
```json
// package.json
{
  "build": {
    "files": [
      "main.js",
      "preload.js",
      "dist-vue/**/*",  // 确保包含 Vue 构建文件
      "package.json",
      "assets/**/*"
    ]
  }
}
```

## 6. 热更新不生效

### 问题描述
修改代码后，浏览器/Electron 没有自动刷新。

### 解决方案

1. **检查 Vite 是否正常运行**
```bash
cd src
npm run dev
# 应该看到 "Local: http://localhost:5173/"
```

2. **清除缓存**
```bash
# 删除 Vite 缓存
rm -rf src/node_modules/.vite

# 重启开发服务器
cd src
npm run dev
```

3. **检查文件监听**
- 确保文件在 `src/src/` 目录下
- 检查是否在 `.gitignore` 中被忽略

    </template>
  </VirtualScroller>

### 图片加载慢

**解决方案：**
```javascript
// 1. 添加图片缓存
const imageCache = ref({})

async function getImageSrc(fileName) {
  if (imageCache.value[fileName]) {
    return imageCache.value[fileName]
  }
  
  const result = await electronAPI.readImage(fileName)
  if (result.success) {
    imageCache.value[fileName] = result.data
    return result.data
  }
  return ''
}

// 2. 懒加载图片
<img :src="imageSrc" loading="lazy" />
```

## 8. TypeScript 类型错误

虽然项目是 JavaScript，但 IDE 可能会显示类型警告。

### 解决方案

```javascript
/**
 * @param {number} id - 任务 ID
 * @param {string} text - 任务文本
 * @returns {Promise<void>}

async function updateTask(id, text) {
  // ...
}
```

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

## 9. 数据丢失

### 问题描述
重启应用后数据丢失。

### 排查步骤

1. **检查数据文件是否存在**
```javascript
// 在 Electron DevTools Console 中运行
const { app } = require('electron')
console.log('userData 路径:', app.getPath('userData'))
```

2. **检查保存是否成功**
```javascript
async function saveTodos() {
  try {
    const result = await electronAPI.saveTodos(todos.value)
    console.log('保存结果:', result)
  } catch (error) {
    console.error('保存失败:', error)
  }
}
```

3. **手动备份数据**
```bash
# Windows
copy %APPDATA%\todox\*.json backup\

# macOS/Linux
cp ~/Library/Application\ Support/todox/*.json backup/
```
